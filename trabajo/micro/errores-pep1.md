# Lista de errores · PEP 1 Micro II

Formato: ítem · qué escribí · **frase correcta** · marcas. Se pregunta tapado al inicio de cada sesión (`plan-paro.md` §3); con 2 aciertos seguidos sale de la lista. Llenada el 10-11 con lo que consta en la bitácora.

| # | Ítem | Qué escribí | Frase correcta | Marcas |
|---|---|---|---|---|
| 1 | Árbol de entrada (simulacro final D1) | Una rama de más | El árbol solo tiene las decisiones reales: el entrante elige entrar o no entrar; el incumbente decide (pelear o acomodar) solo después de «entrar» | |
| 2 | Árbol de entrada | «No entrar está dominada» | Falso: si el incumbente pelea, no entrar es la mejor respuesta. Por eso hay 2 EN; la inducción hacia atrás deja uno solo (ENPS), porque pelear es una amenaza no creíble | |
| 3 | Matriz 3×3, eliminación iterada | Pasos sin números | Cada eliminación lleva la comparación de pagos escrita (p. ej. «4 > 2, 3 > 1, 5 > 0 ⇒ X domina a Z») | |
| 4 | Matriz 3×3, equilibrio | EN como pagos: (3, 2) | El EN es un **perfil de estrategias**: (Y, Q). Los pagos se informan aparte | |
| 5 | Matriz 3×3, a) | Revisé solo al jugador A | La dominancia se revisa para los dos jugadores antes de eliminar | |
| 6 | Dilema repetido | Llamé «cooperar» a confesar | Cooperar = no confesar (mantener el acuerdo). Confesar = desviarse | |
| 7 | Dilema repetido | El papel del castigo, al revés | La amenaza de castigo **reduce** el incentivo a desviarse: la ganancia de hoy se compara con la pérdida futura descontada | |
